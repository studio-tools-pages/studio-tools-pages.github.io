Studio Tools

Studio Tools are two private desktop applications that one creator uses on their own computer. They are not offered to the public and they have no other users.

Studio Publisher

It uploads the creator's own finished Shorts to the creator's own YouTube channel and schedules them. It also reads the upload status and view counts of those videos.

Studio Dashboard

A personal dashboard. It reads the creator's own Google Drive files and YouTube channel statistics so the creator can see them in one place. Only when the creator explicitly allows it for a channel, it uploads and schedules the creator's own finished videos on that channel. It never edits or deletes anything.

See the Privacy Policy for how Google user data is handled.

Personal, non-commercial tools. No accounts, no sign-up, no ads.
