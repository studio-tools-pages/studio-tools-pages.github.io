Privacy Policy

Studio Tools: Studio Publisher and Studio Dashboard. Effective 23 November 2026.

Who uses these apps

Both apps are private desktop tools that only their owner uses, on the owner's own computer, with the owner's own Google account. No other person can sign in or use them.

Google user data the apps access

AppPermissionWhy
Studio PublisherYouTube: upload videosUpload the owner's own finished Shorts.
Studio PublisherYouTube: view accountConfirm the correct channel and read the status and view counts of its uploads.
Studio PublisherYouTube: manage videosSet or change the publish time of its own uploads.
Studio DashboardGoogle Drive: read onlyShow the owner's own backup files and check that backups are complete.
Studio DashboardYouTube and YouTube Analytics: read onlyShow the owner's own channel statistics.
Studio DashboardYouTube: upload videosOnly if the owner enables it for a channel: upload and schedule the owner's own finished videos.

How the data is used

  • The data is used only to provide these functions to the owner.
  • It is never sold, shared, transferred to third parties or used for advertising.
  • It is not used to train AI or machine-learning models.
  • Use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Storage and security

  • Authorization tokens are stored only on the owner's computer, in a location only the owner's Windows account can read. They are never sent anywhere except to Google.
  • The apps have no servers, no databases in the cloud and no analytics.

Retention and deletion

The owner can revoke access at any time at myaccount.google.com/permissions. Revoking access, or deleting the local token file, removes the apps' access immediately.

Changes

If this policy changes, this page will be updated and its effective date changed.
